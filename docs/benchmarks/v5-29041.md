## Failed indexing barrier

Afterimage used a new task-local HOME/cache with `INFIGRAPH_NO_WATCH=1`, `index --full --enriched --no-embed`, and a 720-second timeout. Foreground enriched mode was selected for complete admission; **the owner did not explicitly require SCIP**, and this mode is stricter than merely obtaining syntax-derived structural edges. Its failure does not prove structural CLI queries unavailable.

The partial graph contains 6,671 files, 166,573 symbols and 32,588 Calls edges. Call resolution reported 91,360 resolved and 460,737 unresolved cross-file calls; these are tool counters, not verified accuracy measurements. Compiler preflight then failed with `SCIP_TOOL_UNAVAILABLE` for TypeScript, Rust and Java, and `PROJECT_PREREQUISITE_MISSING` for Clang. Python remains pending. Exit status 1; the graph was not admitted. No fallback to AST-only/BM25, silent repair, tool download, global installation or watcher was used.

Measured wall 126.08 s, user CPU 487.77 s, system CPU 2.11 s, peak RSS 1,818,044 KiB. The evidence includes every partial index file's SHA-256, size and mtime, total bytes, coverage receipt and raw resource output. There is **no successful barrier timestamp**, repeated query qualification, immutable-query receipt, or graph accuracy/false-edge audit. A partial fingerprint is not an admitted immutable index.
